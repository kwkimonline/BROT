# BROT: Barycentric Regression for Optimal Transport

Official repository for **[Deep Barycentric Regression for Optimal Transport Map Estimation and its Statistical Optimality](https://arxiv.org/abs/2609.06598)**.

**Authors:** Kunwoong Kim, Insung Kong, and Yongdai Kim  
**Venue:** NeurIPS 2026 — Spotlight ([author's homepage](https://kwkimonline.github.io/))  
**Paper:** [arXiv:2609.06598](https://arxiv.org/abs/2609.06598)

BROT estimates optimal transport maps by constructing barycentric targets from an unregularized transport plan and fitting a deep neural network to those targets through least-squares regression.

## Code availability

As of October 13, 2026, this public repository contains only `README.md` and `LICENSE`. The implementation, dependency specifications, and training/evaluation scripts have not been published here.
